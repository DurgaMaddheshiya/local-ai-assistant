## 🎯 COMPLETE USER SETUP SCRIPT (Give This to Users)

### **NEW USER COMPLETE SETUP (30 MINUTES)**

#### **STEP 1: Install Ollama (5 Minutes)**

**What is Ollama?**
- The AI engine that powers everything
- Free and open-source
- ~150MB download

**Steps:**
1. Open browser → Go to https://ollama.com/download
2. Click "Download for Windows"
3. Download `OllamaSetup.exe` (~150MB)
4. Double-click the installer
5. Follow wizard: Next → Next → Finish
6. Wait 2-3 minutes
7. **Done!** ✅

---

#### **STEP 2: Download AI Model (15 Minutes)**

**What is this?**
- The brain of the AI (2GB)
- Qwen 2.5 3B model - small, fast, smart
- One-time download

**Steps:**
1. Open Command Prompt (press Windows key, type "cmd", press Enter)
2. Copy this command:
   ```cmd
   ollama pull qwen2.5:3b
   ```
3. Right-click in Command Prompt → Paste
4. Press **Enter**
5. Wait for completion (you'll see progress bar)
6. Takes 5-15 minutes (depends on internet speed)
7. When done, you see: `100% ✓`
8. **Done!** ✅

---

#### **STEP 3: Start Ollama Service (2 Minutes)**

**⚠️ DO THIS EVERY TIME YOU USE THE APP!**

**Steps:**
1. Open Command Prompt (press Windows key, type "cmd")
2. Type: `ollama serve`
3. Press **Enter**
4. You see: `Listening on 127.0.0.1:11434`
5. **⚠️ KEEP THIS WINDOW OPEN!**
   - You can minimize it
   - But DON'T close it
   - If you close it, AI stops working

**Done!** ✅

## 🆘 TROUBLESHOOTING

### Problem: "Ollama service unavailable"
**Fix:**
- Check if `ollama serve` Command Prompt is open
- Is it running? (look for "Listening on 127.0.0.1:11434")
- If not, run it

### Problem: "Model not found"
**Fix:**
- Open Command Prompt
- Type: `ollama pull qwen2.5:3b`
- Press Enter
- Wait for completion

### Problem: "Port 8000 already in use"
**Fix:**
1. Close other applications
2. Or: Open `START.bat` in text editor
3. Change `--port 8000` to `--port 8001`
4. Save and try again

### Problem: Application won't start
**Fix:**
1. Restart your computer
2. Run `ollama serve` in Command Prompt first
3. Wait 5 seconds
4. Then run `START.bat`

### Problem: Very slow responses
**Fix:**
- First response is always slow (normal)
- Close other apps running in background
- Try again
- Later responses are faster

### Problem: "Connection refused"
**Fix:**
1. Make sure `ollama serve` is running
2. Wait 10 seconds
3. Try again
4. If still fails, restart everything
