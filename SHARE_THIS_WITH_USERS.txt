🚀 LOCAL AI ASSISTANT - USER SETUP (30 MINUTES)

Built by @durga.kr2003 on Instagram

STEP 1: Install Ollama (AI Engine)
  → Download: https://ollama.com/download
  → Double-click installer
  → Follow the wizard
  → Done!

STEP 2: Download AI Model
  → Open Command Prompt (search "cmd")
  → Paste: ollama pull qwen2.5:3b
  → Wait for 100% (5-15 min)
  → Done!

STEP 3: Start Ollama
  → Open Command Prompt
  → Type: ollama serve
  → Press Enter
  → Keep this window open!

STEP 4: Extract Application
  → Extract: LocalAIAssistant-Portable.zip
  → Folder appears

STEP 5: Run Application
  → Open LocalAIAssistant folder
  → Double-click: START.bat
  → Browser opens!

STEP 6: Chat!
  → Type message
  → Press Enter
  → AI responds!

EVERY TIME YOU USE:
  1. ollama serve (in Command Prompt)
  2. Double-click START.bat
  3. Chat!
