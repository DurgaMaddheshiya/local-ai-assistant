⏱️  TOTAL SETUP TIME: 30 MINUTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


✅ STEP 1: INSTALL OLLAMA (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

What: Ollama is the AI engine
Where: https://ollama.com/download
Size: ~150MB

Steps:
  1. Download OllamaSetup.exe
  2. Double-click it
  3. Click Next → Next → Finish
  4. Wait 2-3 minutes
  5. Done!


✅ STEP 2: DOWNLOAD AI MODEL (15 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

What: The brain of the AI (2GB download)
Size: ~2GB

Steps:
  1. Open Command Prompt (search "cmd")
  2. Paste this command:
     
     ollama pull qwen2.5:3b
  
  3. Press Enter
  4. Wait for 100% (5-15 minutes)
  5. You'll see: "pulling manifest... 100% ✓"
  6. Done!


✅ STEP 3: START OLLAMA (2 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  DO THIS EVERY TIME YOU USE THE APP!

Steps:
  1. Open Command Prompt (search "cmd")
  2. Type: ollama serve
  3. Press Enter
  4. You see: "Listening on 127.0.0.1:11434"
  5. ⚠️  KEEP THIS WINDOW OPEN!
  6. You can minimize it, but don't close it


✅ STEP 4: EXTRACT APPLICATION (2 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

What: The AI chat application
File: LocalAIAssistant-Portable.zip (10.24 MB)

Steps:
  1. Find the ZIP file (Downloads folder)
  2. Right-click → "Extract All..."
  3. Choose location (Desktop or Documents)
  4. Click "Extract"
  5. Wait 1-2 minutes
  6. Folder "LocalAIAssistant" appears


✅ STEP 5: LAUNCH APPLICATION (1 MINUTE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Steps:
  1. Open "LocalAIAssistant" folder
  2. Find "START.bat" file
  3. Double-click it
  4. Wait 5-10 seconds
  5. Browser opens automatically
  6. See: "Local AI Assistant" chat screen


✅ STEP 6: START CHATTING! (ANYTIME)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Steps:
  1. Type your message (e.g., "Hello")
  2. Press Enter
  3. AI responds!
  
Note: First response takes 30-60 seconds (model loading)
      Later responses are faster


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🆘 QUICK TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Ollama service unavailable"
Fix: Is "ollama serve" running? Check Command Prompt

Problem: "Model not found"
Fix: Run again: ollama pull qwen2.5:3b

Problem: "Port 8000 already in use"
Fix: Close other apps OR change port in settings

Problem: Application won't start
Fix: Restart computer → Start ollama serve → START.bat

Problem: Very slow responses
Fix: Normal for first response. Close other apps. Try again.
