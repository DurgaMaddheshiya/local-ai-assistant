About

Local AI Assistant

A privacy-focused, offline-capable AI assistant running locally on your computer.

⚠️ Important Notice

This project is for educational purposes only.

Please use this application responsibly and ethically. Do not use it for:

  • Creating misleading or false information
  • Generating harmful, abusive, or illegal content
  • Violating privacy or intellectual property rights
  • Automated harassment or spam
  • Bypassing security systems or unauthorized access

Features

  • 100% Private - All data stays on your computer
  • Offline Capable - Works without internet connection
  • Fast & Local - Powered by Ollama LLM
  • Open Source - Fully transparent and customizable

Technology Stack

  • Backend: FastAPI (Python)
  • Frontend: HTML, CSS, JavaScript
  • Database: SQLite
  • AI Engine: Ollama (Local LLM)
