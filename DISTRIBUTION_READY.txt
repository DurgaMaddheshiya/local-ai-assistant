📋 USERS NEED TO DO:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. INSTALL OLLAMA (AI Engine)
   Download: https://ollama.com/download
   Install: Standard Windows installer (next-next-finish)

2. SETUP AI MODEL
   Run in Command Prompt:
   > ollama pull qwen2.5:3b
   (Takes ~10-15 minutes, downloads 2GB)

3. START OLLAMA SERVICE
   Run in Command Prompt:
   > ollama serve
   (Keep this open)

4. EXTRACT & RUN APPLICATION
   Extract: LocalAIAssistant-Portable.zip
   Double-click: START.bat
   Done! Browser opens automatically

5. START CHATTING
   Type message → Press Enter → AI responds!
