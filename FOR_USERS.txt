🚀 QUICK START - 30 MINUTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Get Ollama (AI Engine) - 5 min
  → Download: https://ollama.com/download
  → Double-click installer
  → Next → Next → Finish

STEP 2: Download AI Model - 15 min
  → Open Command Prompt (search "cmd")
  → Copy-paste: ollama pull qwen2.5:3b
  → Wait for 100%

STEP 3: Start Ollama - 2 min
  → Open Command Prompt
  → Type: ollama serve
  → Press Enter
  → Keep this window open!

STEP 4: Extract Application - 2 min
  → Extract: LocalAIAssistant-Portable.zip
  → Folder appears: LocalAIAssistant

STEP 5: Launch - 1 min
  → Open LocalAIAssistant folder
  → Double-click: START.bat
  → Browser opens!

STEP 6: Chat! - Anytime
  → Type message
  → Press Enter
  → AI responds!

💡 HELPFUL TIPS

❓ WHAT IF SOMETHING DOESN'T WORK?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Ollama service unavailable"
→ Check if "ollama serve" is running in Command Prompt

Problem: "Model not found"
→ Run again: ollama pull qwen2.5:3b

Problem: Application won't start
→ Restart computer
→ Run ollama serve first
→ Then START.bat

For more help:
→ See USER_SETUP_GUIDE.md (Troubleshooting section)
